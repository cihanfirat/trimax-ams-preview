## Design Process

Before creating any design:

1. Analyze current page structure
2. Analyze competitor sites
3. Identify UX issues
4. Identify conversion opportunities
5. Define recommended information architecture

When redesigning:

- Prioritize mobile-first experience
- Follow modern B2B service website best practices
- Ensure sections can be realistically built using Avada Builder (code block)
- Use logos under "logos" folder if needed. (clients and partners logos)
